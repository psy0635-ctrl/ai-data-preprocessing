과제/인공지능학습데이터전처리_실습과제3_2601110288_박수용.pdf

작업 내용
- 원본 Flower.py와 Flower2.py는 그대로 보존했습니다.
- 프로젝트에서 기존 Iris 모델을 찾지 못해 Iris용 기본 신경망을 새로 구성했습니다.
- Iris_assignment3.py: 기본 / 증강 / Dropout / 증강+Dropout 비교
- make_iris_report.py: 실측 학습 기록으로 한글 PDF 생성
- verify_iris.py: 재실행 재현성, 저장 모델, 원본 파일 보존, PDF 검증
- iris_results: 그래프, 학습 기록 JSON, 마지막 epoch 결과 CSV, 모델 4개
- project_scan.json: 프로젝트 내 기존 Iris 모델 검색 기록

PowerShell 실행 (이 폴더에서)
& .\.venv\Scripts\python.exe .\Iris_assignment3.py
& .\.venv\Scripts\python.exe .\make_iris_report.py

처음 설치하는 PC에서
uv venv --python 3.11 .venv
uv pip install --python .\.venv\Scripts\python.exe -r .\requirements-iris.lock.txt

재현 검증용 대표 시드 재학습
& .\.venv\Scripts\python.exe .\Iris_assignment3.py --seeds 123 --output .\tmp\iris_recheck
& .\.venv\Scripts\python.exe .\verify_iris.py

전처리와 실험 기준
- Iris 150개 표본을 클래스 비율 유지하여 학습 120개, 검증 30개로 분할합니다.
- 학습 자료에만 StandardScaler를 적합하여 데이터 누수를 막습니다.
- GaussianNoise(0.1)는 표준화된 입력에 학습할 때만 적용합니다.
- Dropout(0.2)는 두 은닉층 뒤에 학습할 때만 적용합니다.
- 같은 시드의 네 조건은 분할, 초기 Dense 가중치, 배치 순서가 같습니다.
- 5개 시드, 조건별 100 epoch를 사용하고 마지막 epoch를 비교합니다.
- 평균 검증 정확도: 기본 92.00%, 증강 93.33%, Dropout 92.00%, 둘 다 92.00%.
- 작은 데이터의 결과이므로 기법의 보편적 우월성으로 해석하지 않습니다.
- 검증 자료와 별개인 외부 테스트 성능을 측정한 결과는 아닙니다.
